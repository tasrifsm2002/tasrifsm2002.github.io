_Microprocessor & Embedded Systems Laboratory_

Built an autonomous robot that interprets colour-encoded commands in real time via three I2C RGB sensors. Developed the full firmware stack, including colour-classification logic and PWM motor control.

**Tools:** STM32 ARM Cortex-M, C firmware, I2C, TCS34725 RGB sensors
